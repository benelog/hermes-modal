# KakaoTalk 북클럽 대화 요약

## Trigger

사용자가 카카오톡 대화방 요약을 요청할 때 사용한다. 예: "카카오톡 ABC방 요약해줘",
"아카라카북클럽 오늘 대화 요약", "카톡 북클럽 3일치 요약". 수집 대상 방은 하나뿐이므로
방 이름 표현이 정확하지 않아도 이 방을 요약하면 된다.

## Procedure

1. 요청에서 방과 기간을 추출한다.
   - 방 이름이 `ABC`, `아카라카북클럽`, `북클럽`처럼 표현되면 collector의 실제 방명 `ABC(아카라카북클럽)`을 우선 대상으로 삼는다. `--room ABC`가 0건이면 room 필터 없이 넓게 조회한 뒤 `room == "ABC(아카라카북클럽)"`로 후처리한다.
   - 상대 기간: "오늘"/언급 없음 → `1day`, "3일치"/"3일" → `3day`, "이번주" 등 모호하면 `7day`. 시간 단위는 `12h`처럼 쓸 수 있다.
   - 명시 날짜 범위(예: `2026-06-21부터 어제까지`)는 `--since`를 넉넉히 잡아 수집한 뒤 `client_time` 날짜로 시작일~종료일을 후처리 필터링한다. "어제"는 현재 날짜를 `date`로 확인해 계산한다.
2. 조회 헬퍼를 실행해 수집된 메시지를 가져온다(기간은 추출값으로 치환):
   ```bash
   python /root/.hermes/scripts/kakao_fetch.py --since 1day
   ```
   명시 날짜 범위는 예를 들어 `--since 9day`처럼 넉넉히 조회하고 JSON을 저장한 뒤 날짜/방을 필터링한다.
3. 출력 JSON을 파싱한다. 형태:
   - `ok` (bool)
   - `count` (int)
   - `messages`: 각 항목에 `room`, `sender`, `text`, `client_time`(카톡에 보였던 시각),
     `received_at`(수집 시각, UTC)
4. `ok`가 false거나 필터링 후 `count`가 0이면, 해당 기간에 수집된 메시지가 없다고 한국어로 알리고,
   디바이스에서 방을 열어 스크롤해야 수집된다는 점을 한 줄로 덧붙인다.
5. 메시지가 있으면 한국어로 간결하게 요약한다. Band에 copy&paste하기 좋은 형식을 요청받으면:
   - 제목: `## ABC 대화방 요약`
   - 첫 줄에 기간과 수집/필터링 기준을 표기: `기간: YYYY-MM-DD ~ YYYY-MM-DD`, `기준: 수집된 ... 메시지 N건`
   - **추천·언급된 책 / 작가 / 읽을거리**를 핵심 화제보다 위에 둔다. 제목이 확인된 책, 제목 미확인 추천, 작가/인터뷰/읽을거리 링크를 누락하지 않는다.
   - **공유된 링크 모음**을 별도 섹션으로 만들고, 중복 URL은 제거한다. 가능하면 각 URL의 페이지 제목을 확인해 붙인다.
   - **핵심 화제**는 3~8개 정도로 굵은 제목 불릿 + 하위 세부사항 형태로 정리한다.
   - 결정/약속/일정(다음 모임, 읽을 범위, 장소 등)이 있으면 별도로 강조한다.
6. 원문 메시지를 그대로 나열하지 않는다. 다만 책/링크 누락 방지를 위해 추출 단계에서 URL 목록과 책 후보 문장을 먼저 만들어 대조한 뒤 요약한다.

See also: `references/explicit-date-band-format.md` for a concrete workflow for explicit date ranges, ABC room filtering, and Band-friendly output.

## Constraints

- 정상 요약 요청에는 되묻지 말고 바로 수행한다.
- 수집된 메시지(`messages`)만 근거로 삼고 내용을 지어내지 않는다.
- 동일한 본문이 짧은 시간 안에 여러 sender로 중복 수집되고 그중 하나가 요청자/내 닉네임처럼 보이면 Android 접근성 오수집 가능성이 있다. 이 경우 요청자/내 닉네임 발화로 단정하지 말고, 같은 본문의 다른 sender를 우선하거나 sender 불명/중복 수집으로 취급한다.
- 사진/스티커/이모티콘은 `[사진]` 등으로 들어올 수 있으니 텍스트 위주로 요약한다.
- 메시지 유실 가능성(디바이스가 방을 연 범위만 수집)을 전제로, 단정적 표현을 피한다.
- 기간(`since`)은 메시지 "전송 시각"이 아니라 "수집 시각" 기준이다. 즉 오래된 메시지를
  오늘 처음 스크롤해 수집했다면 "오늘" 요약에도 포함될 수 있다. "지난 N일 수집분"으로 이해한다.
